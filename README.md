# 🏨 Hotel Booking Cancellation Dashboard

This Excel project presents a comprehensive analysis of hotel bookings and cancellations from 2015 to 2017. It provides insights into booking patterns, guest behavior, room preferences, and cancellation trends for both **city hotels** and **resort hotels**.

## 📌 Project Overview:

- 🔢 **Total Bookings**: 1,19,390  
- 📉 **Total Cancellations**: 44,224  
- 📅 **Time Frame**: 2015 to 2017  
- 🏨 **Hotel Types**: City Hotel & Resort Hotel  

## 📊 Key Dashboard Highlights:

- **Yearly Booking Trends** for both city and resort hotels  
- **Room Type Analysis** (Desired vs. Undesired) and its impact on cancellations  
- **Guest Type Behavior** (Couples, Family, Single) vs. cancellation rate  
- **Monthly Trends** in guest arrivals and cancellations  
- **Cancellation Comparison** between city and resort hotels  
- Interactive slicers for **year** and **month** to filter insights dynamically  

## 🛠️ Tools Used:  
- **Microsoft Excel / CSV** – For cleaning and transforming the dataset and  For interactive dashboard creation.

## 🔍 Insights Derived:
- Higher cancellations were observed in **city hotels** compared to resort hotels  
- **Couples** were the most frequent guests, also contributing to the highest cancellations  
- Guests with **desired room type** had significantly fewer cancellations  
- Peak cancellation months include **May and April**
